# Wills and Succession — issue checklist

Run this list **in order** on every Wills fact pattern. Threshold issues come first. The trigger facts tell you when an issue is live. Rule IDs point to [`rule-statements.md`](rule-statements.md).

**Before you start.** Read the call. Wills calls usually name the claimants ("What rights do W, D and S have in T's estate?"), so the answer is organized **claimant by claimant**, with the threshold issues (validity of the will, characterization) placed first or under the first claimant [`../../00-exam-intel/grader-expectations.md`](../../00-exam-intel/grader-expectations.md) §5.

## A. Threshold

|---|---|---|---|

| 6 | **Barred takers** | Killing; elder abuse; disclaimer | R-WIL-012 to R-WIL-014 |

## Last check

- Did you give **each claimant** a conclusion with a share (fraction or dollars)?
- Did you cite **Probate Code sections** for execution, revocation, anti-lapse and omitted heirs?
- Did you flag the **CP/QCP** half the survivor already owns?
- Did you consider **Trusts** issues if a trust is mentioned (pour-over, revocation, trustee duties)?
