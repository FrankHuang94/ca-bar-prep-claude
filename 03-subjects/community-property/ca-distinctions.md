# Community Property — California distinctions

**Why this file is different.** In most subjects this file contrasts the MBE (general) rule with California law. Community property is **not on the MBE**, and every CP essay is answered **under California law** (the call says so) [S-079]. So there is no "general rule" to write first. This file instead does two things:
1. Contrasts **California's community property system** with the **common-law (separate-property / equitable-distribution) system** used in most states. The State Bar's "State X, a non-community-property state" facts turn on exactly these differences.
2. Gives the decision rules for **quasi-community property and choice of law** when a couple acquired property while domiciled elsewhere.

**The one-line essay rule.** Always apply the California Family Code and Probate Code; mention the other state's law only to explain why California re-characterizes the property (QCP) or why California law does not reach it (out-of-state land at death).

## California community property vs. common-law states: compare and contrast

| Issue | Common-law (separate-property / equitable-distribution) states | California rule | Authority | **What to write on the essay** |
|---|---|---|---|---|
| Ownership during marriage | Title controls; the earning or titled spouse owns the property | Each spouse owns a present, existing and equal one-half of all CP from acquisition | Fam. Code §§ 751, 760 | "Each spouse owns a present one-half interest in the CP regardless of title" (R-CMP-001) |
| What is shared | "Marital property" defined only at divorce, by statute | CP = acquired during marriage while domiciled in CA; SP = before marriage, gift/inheritance, post-DOS earnings | Fam. Code §§ 760, 770, 771 | Characterize asset by asset at acquisition (R-CMP-008) |
| Division at divorce | **Equitable distribution**: court weighs factors (duration, contributions, fault in some states) | **Equal division** of the net community estate; fault irrelevant | Fam. Code § 2550 | "The court must divide the community estate equally" (R-CMP-075) |
| Property acquired before moving to CA | Owned by the titled spouse under the old state's law | **QCP** at dissolution (both spouses domiciled in CA) and at the decedent's death | Fam. Code § 125; Prob. Code §§ 66, 101; Roesch [S-408] | "Had H been domiciled in California, his State X salary would have been CP, so the stock is QCP" (R-CMP-003) |
| Out-of-state land | Governed by situs law | At dissolution it is QCP (§ 125 "wherever situated") but divided without changing title where possible; at death it is **not** QCP | Fam. Code §§ 125, 2660 [S-418]; Prob. Code § 66 [S-404] | Split the answer: dissolution → QCP + § 2660; death → situs law (R-CMP-083, R-CMP-092) |
| Surviving spouse's protection at death | **Elective (forced) share** of the decedent's estate | No elective share; the survivor already owns half of CP and half of the decedent's QCP, plus QCP recapture | Prob. Code §§ 100, 101, 102 [S-403] | "California has no elective share; W's protection is her half of the CP and QCP" (R-CMP-091 to R-CMP-093) |
| Survivor's own out-of-state earnings at death | Survivor's own property | Survivor's own QCP is **not** split; only the decedent's QCP is | Prob. Code § 101 | Note the asymmetry when the survivor was the earner |
| Gifts and inheritances | Separate (non-marital) in most states, but can become marital by commingling | SP; commingling does not change character if traceable | Fam. Code § 770; See; Mix | Trace (R-CMP-028 to R-CMP-030) |
| Growth of separate business during marriage | Active appreciation may be marital (varies) | Apportion by Pereira or Van Camp | Pereira; Van Camp; Beam [S-417] | Apply both formulas (R-CMP-034 to R-CMP-036) |
| Home bought before marriage, paid with marital funds | Varies (reimbursement or marital share) | Pro tanto CP share by formula | Moore; Marsden | Show the Moore/Marsden math (R-CMP-037, R-CMP-038) |
| Separate contributions to joint property | Often treated as a gift to the marriage | § 2640 reimbursement unless written waiver; joint title CP at dissolution | Fam. Code §§ 2581 [S-425], 2640 | "W is reimbursed her traced down payment without interest" (R-CMP-013, R-CMP-042) |
| Changing character during marriage | Gifts and agreements under ordinary contract/gift law | Transmutation needs an **express written declaration**; no part-performance exception | Fam. Code § 852; MacDonald; Benson | Is there a writing that expressly changes ownership? (R-CMP-022, R-CMP-023) |
| Interspousal transactions | Ordinary contract rules in many states | Spouses are fiduciaries; advantage → presumption of undue influence | Fam. Code § 721; Haines | Raise the presumption on every interspousal deed (R-CMP-016) |
| Premarital agreements | Uniform Premarital Agreement Act in many states | California UPAA plus § 1615(c) seven-day and counsel rules; § 1612(c) counsel for support waivers | Fam. Code §§ 1612, 1615 [S-401] | Walk through § 1615(c) factors (R-CMP-019 to R-CMP-021) |
| Management during marriage | Titled spouse controls | Equal management; written consent for gifts, household goods; joinder for real property; business notice | Fam. Code §§ 1100, 1102 | Apply the specific limit (R-CMP-062 to R-CMP-067) |
| Remedies between spouses | General fraud or conversion law | § 1101: accounting; 50% or 100% of concealed asset | Fam. Code § 1101 [S-405] | "W recovers 100% under § 1101(h) if fraud" (R-CMP-068) |
| Creditors | Creditor reaches only the debtor's property (necessaries doctrine aside) | Entire community estate liable for either spouse's debts; § 911 earnings exception; non-debtor's SP protected except necessaries | Fam. Code §§ 910 [S-414], 911, 913, 914 [S-413] | Separate the creditor question from the allocation question (R-CMP-084 to R-CMP-090) |
| Tort of one spouse | Only the tortfeasor's property | CP and the tortfeasor's SP in an order set by community benefit | Fam. Code § 1000 | Apply the § 1000(b) order (R-CMP-088) |
| Personal-injury recovery | Usually the injured spouse's property | CP if the claim arose during marriage, but awarded to the injured spouse at dissolution | Fam. Code §§ 780, 781, 2603 | Characterize, then § 2603 (R-CMP-056, R-CMP-078) |
| Professional degree | A minority of states historically valued it | Not property; § 2641 reimbursement only | Fam. Code § 2641; Sullivan | "The degree is not CP; the community is reimbursed" (R-CMP-046) |
| End of the marital estate | Usually the date of filing or decree | **Date of separation** (expressed intent + consistent conduct) | Fam. Code §§ 70 [S-400], 771 | Apply both § 70 prongs (R-CMP-070) |
| Survivorship ownership | Tenancy by the entirety in some states | No tenancy by the entirety; CP with right of survivorship available | Civ. Code § 682.1; Fam. Code § 750 | Note the form when the call involves death |
| Defective marriages | Putative-spouse doctrine in some states | Putative spouse divides quasi-marital property equally; good faith is subjective | Fam. Code § 2251; Ceja [S-424] | Threshold issue (R-CMP-006) |
| Unmarried partners | Varies | No CP; Marvin contract claims; registered domestic partners = spouses | Marvin; Fam. Code § 297.5 | One line (R-CMP-007) |
| Federal benefits | Federal law controls | Same: Supremacy Clause preempts CP law for designated federal benefits | Hisquierdo; Mansell; Howell [S-423]; Boggs | One paragraph (R-CMP-100 to R-CMP-103) |

## Quasi-community property and choice of law

**Characterize by the law of the domicile at acquisition, then ask whether California re-characterizes it.**

| Scenario | Character | Authority | Write |
|---|---|---|---|
| 1. Couple domiciled in California when the asset was acquired with marital earnings | CP, wherever the asset is located, and it stays CP after a move away | Fam. Code § 760 | "Acquired during marriage while domiciled in California → CP." |
| 2. Couple domiciled in State X (common law) when marital earnings bought the asset; dissolution in California with both spouses domiciled here | **QCP** (personal or real, anywhere), divided equally | Fam. Code §§ 125, 2550; Roesch [S-408]; Fredericks [S-1014] | "Had H been domiciled here, his State X salary would have been CP; the asset is QCP." |
| 3. Same as 2, but only one spouse is domiciled in California at dissolution | California has applied the other state's law instead of QCP | Roesch [S-408] | Flag the domicile issue; argue both |
| 4. Same as 2, and the earner dies domiciled in California | Decedent's QCP: half to survivor (personal property anywhere; California land) | Prob. Code §§ 66, 101 | "One-half belongs to W under Prob. Code § 101." |
| 5. Same as 4, but the asset is **land in State X** | Not QCP at death; State X law governs | Prob. Code § 66 | "California's QCP rules do not reach the State X farm at death." |
| 6. The **survivor** was the earner in State X | The survivor's own QCP is not split; the survivor keeps it | Prob. Code § 101 | Note the asymmetry |
| 7. Earner gave QCP away (e.g., into joint tenancy with a child) and kept control | Survivor may recapture one-half | Prob. Code § 102 [S-403] [S-1002] | Walk through the § 102 elements; note the § 102(b) carve-out for insurance, annuities and pensions |
| 8. Gift or inheritance received in State X | SP (it would have been SP in California too) | Fam. Code §§ 125, 770 | "Not QCP: a gift would be SP even in California." |

**Why California may do this.** Applying QCP at divorce to property acquired before the move satisfies due process because California has a strong interest when both spouses are domiciled here at dissolution (*Addison v. Addison* (1965) 62 Cal.2d 558).

## What to write when the call says "answer according to California law"

1. **Opening paragraph:** California is a CP state; state the § 760 presumption and § 770 SP categories (R-CMP-001, R-CMP-002).
2. **If a move from State X appears:** define QCP and say whether the event is dissolution or death; then apply the correct definition (Fam. Code § 125 vs. Prob. Code § 66).
3. **Asset by asset:** source → time → presumptions → transmutation/agreements → tracing/apportionment → reimbursement → division or disposition.
4. **Never apply equitable distribution, elective-share or common-law title rules** to a California spouse's property; use them only to explain why QCP exists.
5. **Crossovers:** in a Wills crossover, characterize first, then apply testamentary power (Prob. Code § 6101) or intestacy (§ 6401); in a PR crossover, analyze the lawyer's duties separately (California and ABA rules).

> 🇨🇳 PRC bridge: PRC marital-property law is a statutory joint-property system like California's, but it lets courts depart from equal division and treats inheritances as joint by default; when in doubt on an essay, follow the California statute, not the PRC instinct (approx.).
