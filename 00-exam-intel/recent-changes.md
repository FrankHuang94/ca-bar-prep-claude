> **How to use this file.** Each subject's `outline.md` and `ca-distinctions.md` must reflect every item marked **Apply** below. `/update-exam-intel` re-checks this file monthly. Before the exam, re-run it in **June 2027** to catch anything adopted in spring 2027.

**Working rule for this repo**
- Learn the law **in effect on July 27, 2027**.
- Where a rule changed recently, learn both versions and the change itself. A question may avoid the changed point, and MBE items are written well in advance. If a question clearly turns on the point, apply current law.

**Bridge to California.** From Dec 1, 2026 the FRE moves close to California's long-standing rule allowing substantive use of prior inconsistent statements (Evid. Code § 1235). The `evidence/ca-distinctions.md` comparison tables were written for the amended rule in Phase 4.
