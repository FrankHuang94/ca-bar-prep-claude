# Schemas

JSON Schema (draft 2020-12) files enforced by `scripts/validate.py`:

- `content-front-matter.schema.json`: every Markdown file in a numbered folder
- `mcq.schema.json`, `essay.schema.json`, `pt.schema.json`, `simulation.schema.json`

CSV column sets (attempts, flashcards, past-exam indexes) are defined in `scripts/common.py`.
