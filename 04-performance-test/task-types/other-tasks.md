# Other PT tasks

> **How often these appear on California PTs:** to be filled in from [past-pt-index.csv](../past-pt-index.csv) in Phase 3. No frequency is stated until then.
>
> This list covers task types a lawyering-skills exam *could* ask for. It does not claim that each one has appeared on a California PT. Phase 3 will mark which ones have.

**The universal rule:** when the task is unfamiliar, the task memo **is** the template. Turn every sentence of instruction into a heading, then fill each heading with Library rules and File facts ([method.md](../method.md) §4).

## 1. Opening statement
**Purpose:** preview for the fact-finder what the evidence will show, and give them a story and a theme to organize it. It is not argument. The convention in trial practice is that argument is saved for closing.

```text
OPENING STATEMENT ON BEHALF OF [PARTY]
1. Theme (1-2 sentences)
2. The story: chronological, told through the witnesses and exhibits you will present
   ("You will hear from Ms. Ortiz, the warehouse manager, who will tell you...")
3. What the evidence will show on each element / instruction (from the Library)
4. Pre-empt weaknesses the jury will hear about anyway
5. What you will ask for at the end
```

**Mistakes:**
- Arguing ("clearly", "obviously") or attacking credibility.
- Promising evidence that the File shows may be inadmissible or unavailable.
- Personal opinion. ABA Model Rule 3.4(e) applies throughout trial; see [closing-argument.md](closing-argument.md).

**Checklist:**
- [ ] "The evidence will show" framing.
- [ ] Witnesses and exhibits named.
- [ ] Every element previewed.
- [ ] Weaknesses pre-empted.
- [ ] Relief previewed.

## 2. Discovery plan (or discovery requests)
**Purpose:** identify what facts you still need to prove or defeat each element, and the best discovery tool for each, within the Library's procedural rules (scope, limits, privileges).

```text
DISCOVERY PLAN: [Matter]
I.  Elements to prove/defeat (from the Library) and the facts now known (from the File)
II. Gaps: element -> missing fact -> likely source (person/document)
III. Plan (table):
    | Fact needed | Source | Tool (interrogatory, document request, deposition,
      request for admission, subpoena, inspection) | Timing/sequence | Library rule (scope/limits) |
IV. Privilege / work-product / protective-order issues, and how to handle them
V.  Sequence and priorities (e.g., documents before depositions)
```

**Mistakes:**
- Generic requests that are not tied to elements.
- Ignoring the Library's numerical or scope limits and privileges.
- No sequencing.
- Drafting actual requests when the task asked only for a plan, or the reverse.

**Checklist:**
- [ ] Every element has its facts mapped.
- [ ] Each gap has a tool and a source.
- [ ] Library limits applied.
- [ ] Privilege issues flagged.
- [ ] Sequence justified.

## 3. Declaration or affidavit
**Purpose:** a witness's sworn or penalty-of-perjury statement of facts, usually supporting or opposing a motion. Only **personal knowledge**, admissible facts and no legal argument.
- In real practice: California allows declarations under penalty of perjury (Code Civ. Proc. § 2015.5); federal practice allows unsworn declarations (28 U.S.C. § 1746).
- **On the PT, use the form the Library or File supplies.**

```text
DECLARATION OF [WITNESS NAME]
I, [name], declare:
1. I am [role]. I have personal knowledge of the facts stated here and, if called as a
   witness, could and would testify competently to them.
2. [One fact per numbered paragraph, first person, chronological, specific: dates, amounts,
   documents ("A true and correct copy of the invoice is attached as Exhibit A.")]
3. ...
[Attestation language per the Library/File form, e.g., penalty-of-perjury statement]
Executed on [date] at [place].
________________ [Witness name]
```

**Mistakes:**
- Legal conclusions ("Defendant breached the contract").
- Hearsay or speculation outside the witness's knowledge.
- Argument, or adjectives in place of facts.
- Facts the witness does not know.

**Checklist:**
- [ ] First person, numbered paragraphs.
- [ ] Every fact within the witness's personal knowledge.
- [ ] Facts that match the elements of the motion in the Library.
- [ ] Exhibits identified.
- [ ] The correct attestation per the Library or File form.

## 4. Statement of facts (stand-alone)
**Purpose:** a fact section for a brief or memo.
- **Objective** for a memo; **persuasive but accurate** for a brief.
- Every fact is cited to the File (document and page or paragraph).

```text
STATEMENT OF FACTS
[Short orienting paragraph: parties, dispute, procedural posture]
[Chronological or topical subsections with headings, if long]
Each sentence: fact + File citation (e.g., "(Ortiz Dep. 14:3-9)", "(Ex. 4)").
Persuasive version: lead with favorable facts; place unfavorable facts in context (not omitted).
```

**Mistakes:**
- Argument or legal conclusions inside the facts.
- Omitting material bad facts.
- No citations.
- Facts that do not matter to any element.

**Checklist:**
- [ ] Every fact relevant and cited.
- [ ] Neutral or persuasive tone as instructed.
- [ ] Bad facts included (in context).
- [ ] No legal argument.

## 5. Other formats you may meet

| Task | Purpose | Skeleton | Watch out for |
|---|---|---|---|
| **Bench memo / draft judicial opinion** | Help a judge decide; neutral | Issue → Background → Analysis per issue (both sides) → Recommended ruling | Neutrality. Address both parties' arguments. |
| **Proposed jury instructions** | State the law for jurors, from the Library | Numbered instructions in plain English, one element per instruction, with the source authority noted | Accuracy to the Library. No slanted wording. |
| **Witness examination plan (direct or cross)** | Elicit (direct) or control (cross) testimony | Goals → topics → questions (open on direct; leading on cross) → exhibits → anticipated objections | Open questions on direct, leading questions on cross. Tie each topic to an element. |
| **Settlement proposal / negotiation plan** | Advance the client's interests in a deal | Client goals and limits → the other side's interests → options → offer and fallback → terms | Client authority. Ethical limits on statements to third parties (Cal. Rules of Prof. Conduct, rule 4.1). |
| **Internal policy or compliance memo / ethics analysis** | Apply rules to an organization's conduct | Issue → rule (Library) → application → recommendation | Treat the Library's professional-conduct rules as the governing rules for the PT. |
| **Letter to opposing counsel** (non-demand) | Negotiate, meet and confer, or set out a position | As in [demand-letter.md](demand-letter.md), without the demand structure | Rule 4.2 contact rules. Professional tone. |

## Checklist for any unfamiliar task
- [ ] I can name the document, the reader, the tone and the format ([method.md](../method.md) §4).
- [ ] Every sentence of the task memo maps to a heading or an element of my answer.
- [ ] Rules come from the Library, cited by name; facts come from the File, cited where the format expects it.
- [ ] Every requested part exists by 1:20.
