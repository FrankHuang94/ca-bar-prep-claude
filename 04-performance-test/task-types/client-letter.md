# Client letter (advice letter)

> **How often this appears on California PTs:** to be filled in from [past-pt-index.csv](../past-pt-index.csv) in Phase 3. No frequency is stated until then.

## Purpose
Explain to the **client** where they stand legally and what their options are, so that **they** can decide. It is an objective analysis, translated for a non-lawyer, or for a business reader if the File shows a sophisticated client.

You have written to clients and boards in deal work. The skill is the same: **bottom line first, then reasons, then options.**

## Format template

```text
[Firm letterhead, if the task gives one]

[Date]

[Client name]
[Address, if given in the File]

Re: [Plain-English subject, e.g., "Your rights under the lease for 14 Harbor Street"]

Dear [Mr./Ms. Surname]:

[OPENING: 2-4 sentences]
You asked whether [question in the client's terms]. In short, [bottom-line answer, with
the level of confidence]. This letter explains why and sets out your options.

[BACKGROUND: only if the task asks for it, and briefly. Confirm the key facts you relied on,
so the client can correct any mistakes.]

[ANALYSIS: one plain-English heading per issue]
1. [Heading as a question the client would ask, e.g., "Can the landlord end the lease early?"]
   The rule, in plain words, attributed ("Columbia courts have held that...", "A Columbia statute
   requires..."). Name authorities sparingly and explain what they mean.
   How it applies to your facts. What cuts against you. Likely outcome.
2. ...

[OPTIONS AND RECOMMENDATION]
Option A: [what it involves; benefits; risks; cost/time if the File gives them]
Option B: ...
My recommendation: [only if the task asks for one; the decision remains the client's]

[NEXT STEPS / INFORMATION NEEDED]

[CLOSING]
Please call me with any questions.

Very truly yours,

[Role or placeholder name from the task memo; never your real name]
```

## Tone
- **Plain English.** No Latin. Define any unavoidable term the first time ("an 'easement', a right to use someone else's land for a limited purpose").
- **Warm, professional, honest.** Do not promise outcomes; use "likely" and "the risk is". Do not overstate certainty.
- **Fit the reader the File describes:** a worried individual needs reassurance and clarity; a CFO wants a crisp risk summary.
- Short paragraphs; headings as questions; numbered options.

## Common mistakes
| Mistake | Fix |
|---|---|
| Writing a legal memo with "Dear..." on top (case-by-case analysis, citations everywhere) | Name an authority only when it helps the client trust the conclusion, and always explain it. |
| Burying the answer on page 2 | The bottom line goes in the first paragraph. |
| Deciding for the client | Present the options and their trade-offs; recommend only if asked. |
| Guaranteeing success ("you will win") | Use calibrated likelihood language. |
| Ignoring the client's stated goals in the File (e.g., "I want to keep the business relationship") | Measure every option against those goals. |
| Revealing confidential information to a third party copied on the letter | Check the address list. Write only to the client unless told otherwise. |

## Checklist
- [ ] Date, addressee, "Re:" line, salutation, closing; signed by role or placeholder.
- [ ] Bottom-line answer in the opening paragraph.
- [ ] One plain-English heading per issue.
- [ ] Rules explained in plain words, attributed to Library authority.
- [ ] Risks stated honestly.
- [ ] Options measured against the client's own goals.
- [ ] Next steps and missing information listed.
- [ ] Tone matches the client's sophistication.
