# Drafting a will or trust (or selected provisions)

> **How often this appears on California PTs:** to be filled in from [past-pt-index.csv](../past-pt-index.csv) in Phase 3. No frequency is stated until then.

## Purpose
- Turn the client's wishes, as shown in the File (interview notes, letters, family details, asset lists), into **operative provisions** that will work under the Library's law.
- The task often adds a short **explanatory memo** saying why each provision is drafted as it is, and which client wishes cannot be carried out, or carry risks.

**Closed universe:** use the Library's Columbia probate or trust statutes and cases, not the California Probate Code, even where you know it. A wills or trusts PT tests drafting and analysis, not memory.

## Format template

Draft **only** the provisions the task requests. Use the Library's required formalities and any form the File provides.

```text
[TITLE: e.g., LAST WILL OF [NAME]  /  THE [NAME] REVOCABLE TRUST]

[ARTICLE 1. DECLARATIONS / IDENTIFICATION]
1.1 I, [name], of [county], Columbia, declare this to be my will and revoke all prior wills and codicils.
1.2 Family: [spouse; children by name; state who is intentionally omitted, if relevant under the Library]

[ARTICLE 2. DEFINITIONS]            <- define terms that the Library shows are litigated
2.1 "Children" means ... [include/exclude adopted, stepchildren, after-born: per the client's wishes]
2.2 "Survive" means survive by [ ] days.   <- if the Library allows a survival period

[ARTICLE 3. SPECIFIC GIFTS]
3.1 I give [specific asset, described exactly] to [beneficiary], if [he/she] survives me.
    If [beneficiary] does not survive me, this gift [lapses and falls into the residue /
    passes to ...].   <- always state the alternate

[ARTICLE 4. RESIDUE]
4.1 I give the residue of my estate to ... [shares; per stirpes / by representation, as
    defined in the Library; alternates]

[ARTICLE 5. FIDUCIARIES]
5.1 Executor / Trustee: [name]; successor: [name]; bond waived [if the Library permits]
5.2 Guardian of minor children: [name]; alternate

[ARTICLE 6. TRUST PROVISIONS]       <- if a trust is requested
6.1 Trustee shall distribute income/principal for [beneficiary]'s [standard, e.g., health,
    education, support] until [age/event]; then distribute the remainder to ...
6.2 Spendthrift clause [if the Library recognizes it and the client wants it]
6.3 Revocability / amendment method [state it expressly; the Library may make the method matter]

[ARTICLE 7. MISCELLANEOUS]           <- no-contest clause, governing law, etc., only if relevant

[EXECUTION AND ATTESTATION]          <- only if requested; follow the Library's formalities exactly
Signed on [date] at [city], Columbia.
_____________________ [Testator]
[Attestation clause per the Library's statute: witnesses' statements and signatures]

---------------------------------------------------------------
[EXPLANATORY MEMO, if requested]
Provision 3.1: carries out [client's wish]; addresses [risk, e.g., lapse] because [Library rule].
Wish X cannot be implemented as stated because [Library authority]; alternative: ...
```

## Tone
- **Operative and precise.** "I give", "the Trustee shall", "the Trustee may". No narrative ("my client would like...").
- **One idea per numbered provision.** Use the same defined terms throughout, capitalized.
- In the explanatory memo: objective, brief, tied to the Library.

## Common mistakes
| Mistake | Fix |
|---|---|
| No alternate taker (the beneficiary predeceases; a minor beneficiary) | Every gift: "if X survives me; otherwise to Y." Address minors with a trust or custodian, if the Library allows. |
| Ambiguous descriptions ("my car", "my children") | Describe assets exactly. Define class terms (adopted, step-, after-born) per the client's wishes. |
| Ignoring a client wish that the Library makes problematic (e.g., a gift to a witness or drafter; an omitted spouse) | Flag it in the memo, explain the Library rule, and propose a lawful alternative. |
| Copying the client's informal words into the instrument | Translate wishes into operative language. |
| Drafting provisions not requested (a full will when only Articles 3–4 were asked for) | Draft only what the memo asks for. Use the time to explain choices. |
| Applying California rules from memory | Use the Library's rules. If the Library is silent, say so in the memo. |

## Checklist
- [ ] Only the requested provisions; the File's form followed where one is supplied.
- [ ] Every client wish in the File is implemented or expressly addressed.
- [ ] Every gift has a survival condition and an alternate taker.
- [ ] Class terms and key words defined.
- [ ] Fiduciaries and successors named, if requested.
- [ ] Formalities per the Library (execution, attestation, revocation or amendment method).
- [ ] Explanatory memo (if asked) ties each choice to a Library authority by name.
- [ ] Consistent defined terms and numbering; no real names except the File's.
