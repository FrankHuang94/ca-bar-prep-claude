# MBE vs. California: the master flip table

**What this is.** One place for every rule that changes depending on whether you are answering an **MBE question** (federal / majority / Restatement / UCC / ABA rule) or a **California essay**. Built from each subject's `ca-distinctions.md`; the full rule statement is in that subject's `rule-statements.md` under the listed ID, and **the rule-statements entry controls** if anything here reads differently.

**Three rules that never change.**
1. **MBE:** never apply California law. Use the federal or majority rule, or the statute quoted in the question.
2. **Essay:** read the call first. A named code or "California law" controls. Otherwise write the general rule, then add one "In California, …" sentence only where California changes the outcome (§1 below).
3. **Never let the California sentence replace the general rule** unless the call asks for California law.

**Frequency.** "Tagged in N essays" counts come from the Phase 3 index. Tags were inferred from calls, not from the selected answers, so treat them as indicative [VERIFY V-070] [VERIFY V-071].

## 1. When does an essay call for California law?

The official instruction: unless a question expressly asks for California law, answer "according to legal theories and principles of general application" [S-077].

| **Contracts** | General: R2d + UCC Article 2 | No California-law call seen [VERIFY V-071] | General rule + California sentence; cite the UCC |
| **Torts** | General common law / Restatement | — | Majority rule first; "In California, …" in one sentence |

| **Criminal Law & Procedure** | Common law (+ MPC); U.S. Constitution | No call asked for the Penal Code [VERIFY V-071] | No California rules unless asked; Prop 8 sentence in CEC crossovers |
| **Constitutional Law** | Federal | Every call: U.S. Constitution [VERIFY V-071] | Federal only |

**Exam-day procedure.**
1. Copy the call into your answer as headings, then underline any named law.
2. California-only subject (CP, Wills) → California law.
3. Evidence / Civ Pro → follow the named code or forum; if neither is named, give both where they differ.
4. PR → ABA and California for every duty, even when they agree ("California's rule is the same").
5. Everything else → general rule; add the California sentence from the tables below only where it changes the result.

### 3.3 Torts — majority / Restatement vs. California

Source: [`../03-subjects/torts/ca-distinctions.md`](../03-subjects/torts/ca-distinctions.md). **MBE defaults:** joint and several liability, pure comparative negligence, survival and wrongful-death actions available [S-040].

**Same in both:** intent and the intentional torts to the person; conversion; elements of negligence; proximate cause; constitutional defamation rules; abnormally dangerous activities (R2d §§ 519–520).

| Issue | MBE / majority rule | California rule | What to write on the essay | Rule IDs |
|---|---|---|---|---|
| General duty | Duty to foreseeable plaintiffs (*Palsgraf*) | Statutory duty (Civ. Code § 1714); exceptions only where *Rowland* policy factors clearly justify, applied categorically (*Cabral*); no duty for take-home COVID-19 (*Kuciemba*) | State the majority rule; add § 1714 and *Rowland* if D argues "no duty" | R-TRT-019, R-TRT-020 |

### 3.11 Wills, Trusts and Community Property — California-only subjects (where the general rule tempts)

There is no MBE rule. These rows are the **casebook / UPC / UTC / common-law-state rules** that your Fall 2026 course will teach and that an essay answer must **not** apply as the main rule.

**Wills** — source: [`../03-subjects/wills-succession/ca-distinctions.md`](../03-subjects/wills-succession/ca-distinctions.md)
