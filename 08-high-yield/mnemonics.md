# Mnemonics

**Rules for using these aids**
1. An aid is only a retrieval cue. **On the essay, write the rule sentence, never the acronym.**
2. Expand the aid into the full rule, then check it against the rule ID in `03-subjects/<slug>/rule-statements.md`, which wins on any difference.
3. Practise with `/drill <subject>`; when a list keeps slipping, put the aid in its `10-progress/error-log.md` row as the memory hook.

**Type column**
- **repo**: already in a subject's `memorization-list.md` or `rule-statements.md`.
- **generic**: a widely used acronym built from the rule's own words.
- **new**: made for this page from the rule's own words.

None of these copies a commercial course's wording.
