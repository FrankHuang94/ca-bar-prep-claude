# High-yield

This folder holds the **final-stage synthesis** of the repo: what to reread, recite and drill once every subject has been learned.
- **It adds no new law.** Every rule here is distilled from the subject rulebooks in `03-subjects/<slug>/`, and `rule-statements.md` wins if anything differs.
- **Frequency figures** come from [`06-past-exams/frequency-analysis.md`](../06-past-exams/frequency-analysis.md). Essay issue counts are index-level tags: a guide to emphasis, not a prediction.

## Files

| File | What it is | When to use it |
|---|---|---|
| [`most-tested-issues.md`](most-tested-issues.md) | California essay issues by subject (tag counts, last tested, rules, template); MBE categories and sub-topics; a one-page "10 hours left" list | From W18 to choose essay and drill targets; daily in W28–W29 |
| [`memorization-master.md`](memorization-master.md) | Tier counts for all 13 subjects; every must-know rule ID; spaced-repetition schedule; Anki commands; `/drill` self-test protocol | From the first week of study; the backbone of W25–W29 |
| [`mnemonics.md`](mnemonics.md) | 50 memory aids for list-like rules, each with its rule ID and the full rule | When a list will not stick; error-log memory hooks |
| [`top-rules-mbe-subjects.md`](top-rules-mbe-subjects.md) | Top must-know rules for the seven MBE subjects | Second pass (W18–W23) and W28 rereading |
| [`top-rules-california-subjects.md`](top-rules-california-subjects.md) | Top must-know rules for the six essay-only subjects (PR, CP, Wills, Trusts, Remedies, BA) | Second pass (W18–W23) and W28 rereading |
| [`mbe-vs-california-master-table.md`](mbe-vs-california-master-table.md) | Every rule that flips between the MBE and a California essay, with the top 25 flips | Before every essay on a subject that has a flip; W28 and the evening before Day 2 |
| [`crossover-guide.md`](crossover-guide.md) | How the tested subject pairs interlock, with answer skeletons | From W16 (crossover month); before each crossover essay |
| [`final-2-weeks-review.md`](final-2-weeks-review.md) | Day-by-day plan for Mon Jul 12 – Sun Jul 25, 2027, plus the night before and the evening between exam days | W28–W29 and exam week |

## Order of use

1. **During the first and second passes (Nov–Jun):**
   - learn each subject's must-know tier by the schedule in [`memorization-master.md`](memorization-master.md);
   - keep [`mnemonics.md`](mnemonics.md) open while drilling.
2. **From the second pass (W18):**
   - use [`most-tested-issues.md`](most-tested-issues.md) to aim timed essays and `/spot` drills;
   - use [`top-rules-mbe-subjects.md`](top-rules-mbe-subjects.md) and [`top-rules-california-subjects.md`](top-rules-california-subjects.md) to review each subject's core rules;
   - use [`mbe-vs-california-master-table.md`](mbe-vs-california-master-table.md) to sharpen MBE versus essay rules;
   - use [`crossover-guide.md`](crossover-guide.md) for every crossover essay.
3. **Memorization cycles (W25–W28):**
   - work the cold-write check and the exam-ready standard in [`memorization-master.md`](memorization-master.md) §5.
4. **Final two weeks (W28–W29):**
   - follow [`final-2-weeks-review.md`](final-2-weeks-review.md) day by day;
   - every other file here is reread on the days it names.
5. **If time collapses:**
   - do part (c) of [`most-tested-issues.md`](most-tested-issues.md), the 10-hour list, first.
