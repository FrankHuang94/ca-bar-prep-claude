# Memorization master plan

This page joins the 13 subject `memorization-list.md` files into one plan. It adds no rules. The text of every rule is in `03-subjects/<slug>/rule-statements.md`, and that file wins if anything here disagrees. Counts are as of 2026-11-05. Re-run the tier count after any rulebook edit.

## 1. What each tier means

| Tier | What you must be able to do | How you prove it | Where it is tagged |
|---|---|---|---|
| **Must-know** | Write the **"Rule (write this)"** sentence word for word, plus the elements and the MBE vs. CA line (for PR, the CA vs. ABA line) | `/drill` score 3 | `must-know` in `flashcards.csv` and in the lists |
| **Should-know** | Write a two-sentence version with every element and the main exception | `/drill` score 2–3 | `should-know` |
| **Nice-to-know** | Recognize the rule in a fact pattern and state it in one line | MBE accuracy; no drill needed | `nice-to-know` |

## 5. Self-test protocol (`/drill`)

**What `/drill` does** (`.claude/commands/drill.md`):
- It picks rules in this order: rules you missed before, then rules due under §4.1, then must-know rules, then random ones.
- It shows only the ID and title. You type the rule.
- It scores 0–3 and logs each rule with `scripts/quiz.py log --kind drill`.

**Weekly routine**
1. **Weeknights:** run `/drill <subject> 8` on the subject you are studying, plus the decay subject `/today` names.
2. **Sunday:** re-drill every rule that scored 0–1 this week (spaced-repetition.md §5).
3. **For PR, type four parts:** the ABA rule, the California rule, "same/differs", and the reason. A PR rule scores 3 only with its CA vs. ABA line.
4. **For subjects where the MBE and California differ** (Evidence, Torts, Civil Procedure, Criminal), type both versions. Add which one goes on the MBE and which on a California essay.

**Cold-write check, once per subject in each memorization cycle (W25–W28)**
1. Take the subject's row in §3 and the rule titles only.
2. Close everything else and write each must-know rule statement.
3. Compare each one with `rule-statements.md` and mark it 3/2/1/0 by the `/drill` scale.
4. Log every 0–1 with `python scripts/quiz.py log --kind drill …` (this is what `/drill` runs) and add a row to `10-progress/error-log.md` with a memory hook. Use [`mnemonics.md`](mnemonics.md) where a list is the problem.

**Exam-ready standard (suggested)**
- A subject is exam-ready when a 10-rule must-know `/drill` scores 3 on at least 8 rules and nothing scores 0–1.
- Run that check for every subject during the W26–W27 memorization cycles.
- In W28, re-drill any subject that misses the standard every day until it passes.

**Watch for these errors**

| Error | Fix |
|---|---|
| Right rule, missing a qualifier ("substantially outweighed", "informed **written** consent", "at the time of contracting") | The qualifier is usually the point that earns credit. Underline it in the rulebook and say it aloud on the next drill. |
| Writing the MBE rule on a California essay, or the reverse | Re-read the subject's `ca-distinctions.md` row and the rule's "MBE vs. CA essay" line. Drill both versions together. |
| Writing the PRC-law idea instead of the US rule | The 🇨🇳 bridge lines in the rulebook are only approximate. Drill the US wording, never the bridge. |
| Losing numbers | Use each list's numbers table. Do 5 minutes of numbers-only recall on Saturdays in W25–W29. |

## 6. Subject notes that change how you memorize

2. Must-know rules in the **largest MBE blocks**:
   - Civ Pro I, III and V;
   - Torts negligence;
   - Con Law individual rights;
   - Crim constitutional protections;
   - Contracts formation and performance.

   See [`most-tested-issues.md`](most-tested-issues.md) part (b).
3. Must-know rules for **BA, Real Property, Wills and Trusts**.
4. Should-know rules in your weakest subjects (`/weak-spots`).
5. Nice-to-know rules only through MBE review.
